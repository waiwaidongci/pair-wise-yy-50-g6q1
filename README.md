# 印刷拼版预检与打样轮次审批平台

面向印刷生产团队的拼版工作台，支持页面尺寸与印刷规格、Canvas 版位编辑、出血/安全区/折手/页码检查、打样反馈、版本并排对比、审批锁定和可恢复导出任务。

## 技术栈

Vue 3 + PrimeVue + Pinia + Vue Router + TanStack Query + Axios + Canvas + Vite + TypeScript

## 本地运行

```bash
npm install
npm run dev
```

访问 `http://localhost:62050`。

## 核心工作流

- 导入页面尺寸、出血、安全区、折手和装订方向，在 Canvas 中拖拽版位。
- 自动检查页面缺失、出血不足、页序冲突、版位重叠和装订错误。
- 每轮打样记录样张照片、色差反馈、修正说明和负责人决定。
- 版本并排对比、审批锁定，并恢复中断的导出任务。

## 纸张预留账（/paper）

纸批库存、拼版版本和导出任务通过预留单接成一本台账，提交生产前先锁纸再开工：

- **用量核算**：按 `⌈印面数 ÷ 上机版位⌉ × 印数 × (1+放数%) × (1+裁切损耗%)` 算出印张用量，从指定纸批预留。
- **先到先占**：两个调度同时提交同一纸批时，服务端写操作经互斥链串行处理，按全局到达序号占用；后到者只拿到缺口张数和按「规格一致 / 等级差异 / 纸纹不符 / 尺寸不符」分级的可替代纸批列表，可一键改批重算。
- **指纹失效重算**：纸批规格、纸纹方向或剩余数量任一变化都会更新指纹，该批活动预留单全部失效——未开工版本和关联导出任务自动改占可覆盖纸批并继续排队；已开工任务保留已完成分片并单独留档，续作只能在新纸批上补齐，不允许混入旧批。
- **旧任务待复核**：没有预留单号的历史任务一律标记为「待复核」并冻结，重新确认纸批、生成复核预留单后才能恢复占用库存。
- **可预留量（ATP）**：剩余库存减去所有活动预留占用，释放或结单后自动回补。
